# موقع بورتفوليو شخصي عصري (تصميم أبيض مينيماليست)
# Modern Minimalist White Portfolio

موقع ويب بورتفوليو احترافي، فائق السرعة، ومصمم بأسلوب مونوكروم أبيض أنيق (Minimalist White Aesthetic).

---

## ✨ المميزات الرئيسية (Key Features)

1. **تصميم أبيض مينيماليست راقٍ (Pure Minimalist White)**:
   - خلفية بيضاء نقية مع هوامش دقيقة وتدرجات رمادية ناعمة.
   - خطوط أنيقة تدعم العربية (Cairo) والإنجليزية (Plus Jakarta Sans).
   - تباين عالي ومريح للعين مع تفاعلات حركية ناعمة.

2. **ثنائي اللغة بالكامل (Bilingual AR / EN)**:
   - تبديل فوري بضغطة زر بين العربية والإنجليزية مع تعديل تلقائي للاتجاه (RTL / LTR).
   - حفظ تفضيل اللغة تلقائياً في المتصفح.

3. **أقسام متكاملة (Complete Portfolio Sections)**:
   - **الرئيسية (Hero)**: تعريف سريع، شارة الحالة (متاح للعمل)، أزرار الإجراءات السريعة، وإحصائيات رقمية.
   - **من أنا (About Me)**: نبذة شخصية، إطار الصورة الهندسي، و 4 ركائز خدماتية أساسية.
   - **المهارات (Skills)**: مصنفة إلى (الواجهات الأمامية، الخوادم وقواعد البيانات، UI/UX، الأدوات والنشر).
   - **معرض المشاريع (Projects Portfolio)**: نظام فلترة ديناميكي + نافذة منبثقة تفاعلية (Modal) لعرض تفاصيل كل مشروع مع روابط المعاينة المباشرة وكود GitHub.
   - **المسار المهني (Career Timeline)**: تسلسل زمني أنيق للخبرات الوظيفية والمؤهلات الأكاديمية.
   - **آراء العملاء (Testimonials)**: بطاقات تقييمات الشركاء والعملاء.
   - **تواصل معي (Contact)**: معلومات التواصل، زر نسخ البريد بنقرة واحدة مع إشعار Toast، ورابط واتساب فوري، ونموذج مراسلة تفاعلي.

## 🚀 كيفية التشغيل (How to Run)

الموقع مبني بـ HTML5 + Tailwind CSS + Vanilla JS بدون الحاجة إلى تثبيت أي حزم ثقيلة!

### الطريقة الأولى: التشغيل المباشر
- قم بفتح ملف `index.html` في أي متصفح (Chrome, Edge, Safari, Firefox) بالنقر المزدوج عليه.

### الطريقة الثانية: عبر خادم محلي (Live Server)
إذا كنت تستخدم VS Code أو سطر الأوامر:
```bash
# باستخدام Python:
python -m http.server 3000

# أو باستخدام npx serve:
npx serve .
```
ثم افتح: `http://localhost:3000`

## 🎨 كيفية التخصيص (How to Customize)

1. **تعديل البيانات الشخصية واللغات**:
   - افتح ملف `script.js` وقم بتعديل كائن `translations.ar` و `translations.en` لتغيير اسمك، نبذتك، وروابطك.
2. **تعديل المشاريع**:
   - في `script.js` ستجد كائن `projectsDetails`؛ يمكنك إضافة أي عدد من المشاريع وتحديد الصور، الروابط، والتقنيات.
3. **تغيير البريد ورقم الواتساب**:
   - ابحث في `index.html` و `script.js` عن:
     - `ahmed.dev@example.com`
     - `+966500000000`
     وقم باستبدالها ببياناتك الحقيقية.
